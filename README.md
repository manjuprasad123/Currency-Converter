# 💱 Currency Converter

A modern and responsive **Currency Converter** built using **HTML, CSS, and JavaScript**. This application converts currencies in real time using a free exchange rate API and displays country flags for the selected currencies.

## ✨ Features

* 🌍 Convert between **150+ world currencies**.

* 🔄 Switch between "From" and "To" currencies.

## ⚙️ How It Works

1. Enter an amount.
2. Select the source currency.
3. Select the destination currency.
4. Click **Get Exchange Rate**.
5. The app fetches the latest exchange rate and displays the converted amount.

### Example

```text
Amount: 100
From: USD 🇺🇸
To: INR 🇮🇳

Output:
100 USD = 8,756.42 INR
```

## 🌐 API Used

### Exchange Rate API

```text
https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies
```

### Country Flags API

```text
https://flagsapi.com/{COUNTRY_CODE}/flat/64.png
```

Example:

```text
https://flagsapi.com/IN/flat/64.png
```
